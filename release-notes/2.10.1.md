Bug fix release: a Cloudflare Turnstile setting changed from its default value now takes effect as soon as it is saved.

## Fixed

- **Turnstile settings saved at once.** When a Turnstile setting (the widget appearance, the site key or the secret key) still had its default value (appearance *Only when Cloudflare needs the visitor*, or an empty key) and was changed, the rest of that request still read the old value. On sites with a persistent object cache (Redis, Memcached) the old value was kept in the cache: the Spam protection page showed it after saving and forms kept using it until the cache was flushed. The new value is now read back right away. The settings stay out of WordPress's autoloaded options, as before.

## Updating

From the WordPress admin: Plugins → update "LCMT Mailer". If a Turnstile setting did not seem to save, open Email templates → Spam protection → Cloudflare Turnstile after updating and check it; on a site with a persistent object cache, flush the cache once if it still shows the old value.
