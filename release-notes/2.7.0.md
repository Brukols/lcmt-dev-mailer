Cloudflare Turnstile is now available next to ALTCHA, and each email template chooses its own spam protection. Messages blocked by the protection are no longer lost: they are kept in **Received messages → Spam**.

## Cloudflare Turnstile

- **New spam protection**, in **Email templates → Spam protection**: Cloudflare Turnstile, which is mostly invisible to visitors. Create a widget in your Cloudflare account, then paste the site key and the secret key on that page, or define `LCMT_MAILER_TURNSTILE_SITE_KEY` and `LCMT_MAILER_TURNSTILE_SECRET_KEY` in `wp-config.php` (recommended; the page shows the lines to copy). A connection status tells you whether the keys work.
- **Light on the page**: Cloudflare's script is only requested when a visitor starts filling in a Turnstile form, never on pages without one.
- **If Cloudflare cannot be reached**, the message is refused by default. The same page lets you accept it instead.

## One protection per form

- **New "Spam protection" setting on each email template**: *Site default*, *None*, ALTCHA or Turnstile. Templates without a choice follow the site default, so nothing changes until you pick one.
- A protection that is not set up yet falls back to the site default; *None* always means no protection.
- Each page only loads the scripts of the protections its forms use.

## Blocked messages are kept

- A message refused by the spam protection is saved in **Received messages → Spam** with the reason (*blocked by the spam protection*, or *the verification service did not answer*). It is never emailed.
- The second case is most likely a real visitor: take it out of spam with **Mark as unread**, then use **Send the email again**.
- Only messages whose fields are valid are kept, at most 50 per hour, and the feature can be turned off in **Email templates → Spam protection**.
- **Spam is now deleted after 30 days by default**, blocked or marked by hand, for good (no trash). Change it in **Email templates → Data retention**; `0` keeps spam as long as other messages.

## Encrypted keys

- The ALTCHA key and the Turnstile secret key stored in the database are now **encrypted**. The ALTCHA key is encrypted automatically the first time it is used after the update; nothing to do.
- **Changing the WordPress security keys** (`AUTH_KEY`, `SECURE_AUTH_SALT`, for example after a hack or when the database is copied to another site) makes the stored keys unreadable. The Turnstile protection then stops protecting forms, an admin notice asks you to enter the key again, and **one email** is sent to the site's admin address. Open **Email templates → Spam protection**, enter the Turnstile secret key again and save. An unreadable ALTCHA key is simply regenerated. To avoid this, keep the keys in `wp-config.php`, or define `LCMT_MAILER_ENCRYPTION_KEY` so the encryption no longer depends on the security keys.

## For developers

- Post meta `_lcmt_mail_captcha` holds a template's choice (`''` site default, `none`, or a provider id).
- New interface `CaptchaAssets` (`enqueueAssets()`) for providers with their own scripts, and exception `CaptchaUnavailable` to report that a verification service gave no answer.
- New filter `lcmt_mailer_blocked_hourly_limit` (default `50`).
- The front-end scripts are split per protection (`captcha-altcha.js`, `captcha-turnstile.js`) behind an adapter contract `{ id, field, token, reset }`; see `.claude/frontend.md`.

## Updating

From the WordPress admin: Plugins → update "LCMT Mailer".

- **Purge your page cache** (and your optimisation plugin's cache) after updating, so cached pages carry the new scripts. A cached page older than the update loads the missing script itself, but script optimisers that combine or delay scripts can prevent it: until the cache is purged, such a page may make a visitor wait 30 seconds and see an error.
- **Spam older than 30 days is deleted** at the next daily purge. Set **Delete spam after** on the Data retention page to `0` first if you want to keep it.
- To use Turnstile: create the widget in Cloudflare (list your production and staging hostnames), add the keys, then choose Turnstile on the email templates that need it.
