Performance release: pages showing a form make fewer database queries. Nothing changes in how forms are displayed, validated or sent.

## Performance

- **Settings read in one query**: the three settings a public page needs (storing attribution without consent, the captcha provider and the ALTCHA key) are not loaded with WordPress's autoloaded options, so each one used to cost a database query of its own on every page. They are now fetched together, in a single query, before the page's scripts are set up. Requires WordPress 6.4 or later; on older versions the plugin reads them one by one, as before.
- **No effect on sending**: form submissions go through the plugin's REST endpoint, which this change does not touch. Messages are sent exactly once, as before.

## Updating

From the WordPress admin: Plugins → update "LCMT Mailer".
